#1

Lowዝቅተኛ

Clicking the FXLeag logo navigates home but the cursor never changes to a pointer on hover. Users have no visual cue the logo is clickable. የFXLeag ሎጎን ሲጫኑ ወደ መነሻ ይሄዳሉ፤ ነገር ግን ጣቱ ሲቀርብ የጣት ምልክት አይታይም። ሎጎው ሊጫን የሚችል መሆኑን ተጠቃሚዎቹ አያውቁም።

✅
Fixመፍትሔ Add cursor:pointer to the logo CSS — one line of code. cursor:pointer ወደ ሎጎው CSS ያክሉ — አንድ መስመር ብቻ ነው።
#2
Dashboard accessible without login ዳሽቦርድ ሳይገቡ ይከፈታል
Securityደህንነት Bugሳንካ
Criticalወሳኝ

The Dashboard link on the landing page opens the full dashboard without any authentication. Any visitor can bypass login and view private data. ዋና ገጹ ላይ ያለው ዳሽቦርድ አዝራር ሳይገቡ ሙሉ ዳሽቦርዱን ይከፍታል። ማንኛውም ጎብኚ ምስጢር ማየት ይችላል።

✅
Fixመፍትሔ Add an auth guard on the dashboard route. Redirect unauthenticated visitors to login, then back after sign-in. ዳሽቦርዱን ወደ ሚጎቡ ሁሉ ምርመራ ያስቀምጡ። ያልገቡ ሰዎች ወደ ሎጊን ይላኩ፤ ከዚያ ተመልሰው ይምጡ።
#3
No Back button on login page ወደ ኋላ የሚመልስ አዝራር የለም
Bugሳንካ UX
Mediumመካከለኛ

There is no way back to home from the login screen. Users who want to re-read instructions are stranded — forced to refresh or use the browser back button. ከሎጊን ገጽ ወደ መነሻ ለመመለስ መንገድ የለም። መመሪያዎቹን ለማንበብ ፈልጎ ያልሄደ ሰው ተጣብቆ ይቀራል።

✅
Fixመፍትሔ Add a "← Back to Home" link in the top-left corner of the login page. "← ወደ መነሻ" አዝራር ከሎጊን ፎርሙ ላይኛ ግራ ማዕዘን ያስቀምጡ።
#4
Certificate downloads before course completion ሰርተፊኬት ኮርሱ ሳይጠናቀቅ ይወርዳል
Securityደህንነት Bugሳንካ
Criticalወሳኝ

The certificate download button is active before the course is finished. Anyone can get it on day one — making it completely worthless. የሰርተፊኬት ወረዳ አዝራሩ ኮርሱ ሳይጠናቀቅ ይሰራል። ማንኛውም ሰው ቀን ሲጀምር ሊወርደው ይችላል — ሰርተፊኬቱ ትርጉም አልባ ይሆናል።

✅
Fixመፍትሔ Lock the download with a server-side 100% completion check. Disable the button until the backend confirms the course is done. ሰርቨሩ 100% ማጠናቀቅ ሲያረጋግጥ ብቻ ያስወርዱ። ይህ ምርመራ ሁልጊዜ ከሰርቨር ጎን ሊሆን ይገባዋል።

Email button opens OS app-picker, not Gmail ኢሜይል አዝራሩ Gmail አይከፍትም
Bugሳንካ
Highከፍተኛ

Clicking the contact email button opens the OS app-picker dialog. After choosing an app nothing loads — the contact flow is fully broken. ኢሜይሉን ሲጫኑ የስርዓቱ መተግበሪያ ምርጫ ይወጣል። ምን ቢመርጡ ምንም አይከፈትም — ፈጽሞ አይሰራም።

✅
Fixመፍትሔ Use a plain mailto: link or embed an on-page contact form so no external app is needed. ቀላል mailto: አገናኝ ይጠቀሙ ወይም በቀጥታ ሳይቱ ላይ ቅጽ ያስቀምጡ።
#6
Numbers-only password accepted ቁጥር ብቻ ያለ ፓስወርድ ይፈቀዳል
Securityደህንነት Bugሳንካ
Criticalወሳኝ

Registration accepts a password made entirely of numbers (e.g. 123456). Zero complexity requirement — every account is trivially easy to brute-force. ምዝገባ ፎርሙ ፓስወርዱ ሙሉ ቁጥር ቢሆን ይፈቅዳል (ለምሳሌ 123456)። ምንም ጥንካሬ አያስፈልግም — ሁሉም መለያ በቀላሉ ሊጠቃ ይችላል።

✅
Fixመፍትሔ Require minimum 8 characters mixing uppercase, lowercase, numbers, and symbols. Show a live strength bar. ቢያንስ 8 ፊደላት፤ ትልቅ፣ ትንሽ ፊደል፣ ቁጥርና ምልክት ይጠይቁ። ቀጥታ ጥንካሬ አመልካች ያሳዩ።
#7
Fake email accepted at registration የሐሰት ኢሜይል ምዝገባ ይፈቀዳል
Securityደህንነት Bugሳንካ
Criticalወሳኝ

A generated or non-existent email passes registration. Fake-email accounts cannot be recovered and let spammers flood the system. የሐሰት ወይም የሌለ ኢሜይል ምዝገባ ያልፋል። እነዚህ መለያዎች አይመለሱም፤ ስፓምን ያስፋፋሉ።

✅
Fixመፍትሔ Send a one-time verification link on registration. Block login until the email is confirmed. ምዝገባ ሲደረግ አንድ ጊዜ ብቻ የሚሰራ አረጋጋጭ አገናኝ ይላኩ። ኢሜይሉ እስኪረጋገጥ ድረስ ሎጊን ይዘጉ።
#8
Country field allows manual edit የሀገር መስክ ሊቀየር ይችላል
Bugሳንካ
Highከፍተኛ

The profile country field is freely editable. Any user can change their country, undermining regional compliance and accurate analytics. የመገለጫ ሀገር መስክ ማንኛውም ሰው ሊቀይረው ይችላል። ይህ ሀገራዊ ደንቦችን ያበላሻል።

✅
Fixመፍትሔ Auto-detect country from IP at registration and lock the field to read-only. ምዝገባ ሲደረግ ሀገሩን ከIP ይለዩ፤ መስኩን ለማንበብ ብቻ ያድርጉት።
#9
Navigation needs expandable sub-menus ናቪጌሽን ሊዘረጋ የሚችል ንዑስ ምናሌ ያስፈልገዋል
Improvementማሻሻያ UX
Mediumመካከለኛ

The navigation shows all links at once — cluttered and overwhelming. Apps like TikTok only show top-level sections; clicking one expands its children inline. ናቪጌሽኑ ሁሉንም አገናኞች አንድ ጊዜ ያሳያል — ሞልቶ ይታያል። TikTok ዋና ክፍሎቹን ብቻ ያሳያል፤ ሲጫኑ ንዑሶቹ ይዘረጋሉ።

✅
Fixመፍትሔ Group nav into top-level sections (Tools, Learn, Profile). Each expands on click and collapses when another opens. ናቪጌሽኑን ወደ ዋና ምድቦች ይከፋፍሉ (መሳሪያዎች፣ ትምህርት፣ መገለጫ)። ሲጫኑ ይዘረጋ፤ ሌላ ሲጫኑ ይዘጋ።

No "Continue with Google" sign-in "በGoogle ቀጥሉ" አማራጭ የለም
Improvementማሻሻያ UX

No social sign-in on login or registration. "Continue with Google" is a baseline expectation on modern platforms — it removes friction and increases sign-ups. ሎጊን ወይም ምዝገባ ላይ ማህበራዊ ፈጣን መግቢያ የለም። "በGoogle ቀጥሉ" ዘመናዊ ፕላትፎርሞች ሁሉ ያሉት ነው።

Fixመፍትሔ Integrate Google OAuth 2.0. Add the official "Continue with Google" button above the email form on both pages. Google OAuth 2.0 ያዋህዱ። ሎጊን እና ምዝገባ ሁለቱ ላይ "በGoogle ቀጥሉ" አዝራር ያስቀምጡ።

Improvementማሻሻያ UX

Fixመፍትሔ Update the AI system prompt to reply in short plain sentences. Bullet points only for lists. Tone like a knowledgeable friend. AI ሲስተም ፕሮምፕቱን አጭር ቀላል ዓረፍተ ነገር እንዲጠቀም ያዘምኑ። ቃናው እንደ ጓደኛ ሊሰማ ይገባዋል።

Notifications can only be cleared all at once ማሳወቂያዎች አንድ ጊዜ ሁሉ ብቻ ይጸዳሉ

Fixመፍትሔ Add an individual dismiss (×) button to every notification. Keep "Clear All" as a secondary option. እያንዳንዱ ማሳወቂያ ላይ የራሱ × (ዝጋ) አዝራር ያክሉ። "ሁሉንም ጥረግ" እንደ ሁለተኛ አማራጭ ይቆይ።

Criticalወሳኝ

The CSV export downloads every user's data, not just the logged-in user's. This is a critical privacy breach — users can see other people's trading records. CSV ወረዳ የሁሉም ተጠቃሚ መረጃ ያወርዳል — የተጠቃሚው ብቻ ሳይሆን። ይህ ከባድ ግላዊነት ጥሰት ነው።

Fixመፍትሔ The export API must filter by user_id = current_user.id at database level. Client-side filtering is not acceptable. ወረዳ API user_id = current_user.id በዳታቤዝ ደረጃ ማጣሪያ ሊኖረው ይገባዋል።

#21
API flooded with 401 errors & WebSocket timeouts API በ401 ስህተቶች እና WebSocket ችግሮች ተጥለቅልቋል

Criticalወሳኝ

The browser console on the leaderboard page floods with 200+ errors every session. Every call to api-test.fxleague.com/api/v1/auth/ws-ticket returns HTTP 401 (Unauthorized). WebSocket connections also fail with ERR_CONNECTION_TIMED_OUT. This means the real-time leaderboard never loads, live position updates do not work, and the app silently fails for every user. The errors repeat in a loop — 170+ per session — draining mobile battery and wasting bandwidth. ሊደርቦርድ ገጹ ላይ አሳሹ ኮንሶል በሁሉ ሴሽን 200+ ስህተቶች ያሞላል። api/v1/auth/ws-ticket ለሚደረጉ ሁሉ ጥሪዎች HTTP 401 ምላሽ ይሰጣል። WebSocket ግንኙነቶችም ደጋግመው ይወድቃሉ። ቀጥታ ሊደርቦርድ ውሂቡ ጭራሽ አይጫናም። ስህተቶቹ ደጋግሞ ይሸከረከራሉ — 170+ በሴሽን — ባትሪ ያባክናል።

✅
Fixመፍትሔ 1. Investigate why /auth/ws-ticket returns 401 — the token or session handshake is broken for all users. 2. Add retry backoff so the client does not spam hundreds of failed requests per session. 3. Fix WebSocket reconnection to wait before retrying. 4. Add server monitoring (e.g. Sentry) to alert on 401 spikes before users notice. 1. /auth/ws-ticket ለምን 401 እንደሚመልስ ያጣሩ። 2. ደንደኛ ሙከራ ሎጂክ ያክሉ። 3.
